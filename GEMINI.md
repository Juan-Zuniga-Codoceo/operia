Proyecto Operia: Sistema de Gestión OperativaEste proyecto es un sistema de gestión de tareas y documentación (Task Management System) que utiliza una arquitectura basada en Node.js/Express para el backend y Vue.js 3 (CDN) para el frontend, con SQLite3 como base de datos ligera.
